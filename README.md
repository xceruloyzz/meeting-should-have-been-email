Entry for the [The Meeting That Should Have Been an Email](https://make.fun/c/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) bounty on make.fun — one line, at most 200 characters, making a meeting-that-should-have-been-an-email funny.

## The entry

> We held a meeting to decide whether the meeting could have been an email, and the answer is in the meeting notes nobody will ever read.

135 characters. `main.py` writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) — directly to the final file, no temp files, no trailing newline.

## Run

```sh
python3 main.py
```
